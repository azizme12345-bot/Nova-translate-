Privacy Policy

Last updated: 16 November 2026

This Privacy Policy explains clearly and honestly how LAFZ Translation collects, processes, and stores information when you visit our website—including the Home page, Urdu to English translator, Urdu to Arabic translator, and informational pages. We wrote this policy directly around the technical behavior implemented in this application and identify items that depend on external hosting configuration and require operator confirmation.

Information Collection and Personal Information

LAFZ Translation does not require registration, user accounts, passwords, names, or email profiles to use any translation tool. Our application does not maintain a user database or collect personal profile information through sign-up forms.

The only personal contact details processed outside your own device are those you choose to share voluntarily if you send an email to [CONTACT EMAIL]. Information included in direct support messages is used solely to read and reply to your inquiry.

Website Usage Data and Rate Limiting

When your browser calls our server translation or Camera OCR endpoints, the backend reads your request IP address (from connection headers) temporarily in volatile server memory solely to enforce abuse and rate-limit protection—currently up to 30 requests per minute on AI translation and OCR routes and 60 requests per minute on general API routes. Expired rate-limit records are automatically cleared from memory every five minutes and are not written to a permanent user database by our application code.

Requires operator confirmation: Standard web hosting and edge network providers (such as Vercel, if used in production) may automatically record routine HTTP request logs—such as IP addresses, browser user-agent strings, request timestamps, and status codes—for operational reliability and security. Specific server-log retention policies on the deployed host should be confirmed directly by [OWNER NAME].

Cookies, Browser Storage, and Offline Cache

Our application code does not set browser HTTP cookies or run third-party advertising trackers or behavioral analytics scripts. Instead, LAFZ Translation uses two client-side browser storage mechanisms directly on your device:

Browser localStorage

To make everyday translation faster and easier, the application stores recent translation history (up to 100 entries), your Saved favorite phrases, a 7-day translation cache (up to 250 recent phrase pairs), and your preferred Male or Female voice pitch toggle inside your browser's localStorage. These items stay locally inside your browser, are not synced across other devices, and can be deleted anytime using the Clear buttons or your browser settings.

Progressive Web App (PWA) Service Worker Cache

Our Service Worker caches core static shell files (such as the HTML shell, web manifest, and application icons) in your browser's Cache Storage so the interface loads reliably. Requests sent to translation API routes are explicitly excluded from Service Worker caching.

Translation Text, Voice Input, and Camera OCR Handling

Typed Text Translation

Text you submit for translation (up to 5,000 characters) and your chosen language pair are transmitted over HTTPS to our backend endpoint and forwarded to the Google Gemini API to generate a translation. If the primary model is unavailable, the backend falls back to Google Translate's public endpoint for text delivery. Our server also keeps an in-memory cache of recent translations in process RAM (up to 2,000 entries for up to 48 hours) to speed up repeated requests.

Camera and Photo OCR Processing

When you upload an image or capture a photo in Camera OCR, your browser resizes the image client-side via Canvas before sending it over HTTPS to our backend and onward to the Google Gemini API so printed text can be extracted and translated. Our application does not store uploaded photos in a permanent database; the extracted text and translated text are saved only into your browser's local history.

Microphone Voice Input and Listen Playback

Microphone input relies strictly on your browser's built-in SpeechRecognition interface and does not upload audio recordings to our backend. When using Google Chrome, speech recognition is handled by Google's speech recognition service. Spoken Listen buttons use strictly your browser and operating system's built-in speech synthesis engine without downloading server audio.

Third-Party Services

Depending on which features you use, requests interact with Google Gemini (for text translation and Camera OCR), Google Translate fallback when needed, Google Fonts (for loading Inter and Manrope typography), your browser vendor's speech recognition or synthesis engine, and the website hosting infrastructure. Each third-party service processes requests under its own privacy terms.

Data Security and Sensitive Information

All API keys required for Gemini remain secured on the server and are never placed in frontend HTML or JavaScript. Our server applies standard protective HTTP headers (such as nosniff and same-origin frame restrictions) alongside same-origin checks on API endpoints. Because translation inputs are sent across networks to automated AI services, please do not enter passwords, bank card numbers, national IDs, or confidential medical records.

Data Retention

In-memory translation caches and rate-limit counters reset automatically when server memory expires or restarts. Browser localStorage items stay on your device until you clear them. Retention periods for direct support emails or hosting-level access logs are not controlled inside the code and require confirmation by [OWNER NAME].

Your Privacy Rights

You control your local browser data and device permissions at all times: you may clear history, saved phrases, and cached translations directly in the interface or browser storage settings, and you may block or revoke microphone, camera, and clipboard permissions in your browser at any time.
